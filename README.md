# PRODIGY_CS_02

## Image Encryption Tool using Pixel Manipulation

### Description
This project is developed as part of the Prodigy InfoTech Cyber Security Internship (Task-02).

The Image Encryption Tool encrypts and decrypts images using a simple pixel manipulation technique. It modifies the pixel values of an image using a secret key to create an encrypted image and restores the original image using the same key.

### Features
- Upload an image
- Encrypt the image using a secret key
- Decrypt the image using the same key
- Save encrypted and decrypted images

### Technologies Used
- Python
- NumPy
- Pillow (PIL)
- Google Colab

### Project Files
- `image_encryption.py`
- `README.md`
- `encrypted.png`
- `decrypted.png`
- `original_image.jpg`

### How to Run
1. Install the required libraries:
   ```
   pip install pillow numpy
   ```
2. Run the Python program.
3. Upload an image.
4. Enter an encryption key (1–255).
5. The program generates encrypted and decrypted images.

### Output
- Original Image
- Encrypted Image
- Decrypted Image
